# Pixel Mood

Год настроения и привычек. Цвет клетки — настроение, точка внутри — закрытые привычки.

## Локальный запуск

Нужны Node.js 22 и npm.

```bash
git clone https://github.com/hattory1009/pixel-mood.git
cd pixel-mood
npm install
npm run dev
```

Откройте [http://localhost:8080](http://localhost:8080).

База для разработки поднимается сама, отдельный Postgres не нужен. Регистрация — российский номер (`+7` или `8`, это один телефон) и пароль от 8 символов.

Сетка года хранится в браузере. Имя, фото, друзья и общий календарь — в локальной базе этого запуска.
