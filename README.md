# Pixel Mood

Год настроения и привычек. Цвет клетки — настроение, точка внутри — закрытые привычки.

- Регистрация и вход по российскому номеру. `+7` и `8` — один и тот же телефон.
- Несколько аккаунтов на устройстве, у каждого своя сетка.
- Друзья и переписка. Принятый друг может открыть ваш год только для просмотра.

```bash
npm install
npm run dev
```
